## Quick Start

### 1. Get API Key (FREE!)

```bash
# Sarvam AI (Indian languages - FREE!)
# Visit: https://dashboard.sarvam.ai/
```

### 2. Deploy in 60 Seconds

```bash
curl -sL get.clawops.in | bash
```

### 3. Configure

```bash
# Edit config
nano ~/.clawops/config/openclaw.json

# Apply template
./scripts/templates.sh --apply hr-assistant-hindi
```

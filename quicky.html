Quicky

Stop chasing people for status updates. Let Quicky do it.

What It Does

Quicky automates the painful process of collecting daily status updates from your team. Set it, forget it.

📱 Sample Interaction

Manager: "Add Rahul for warehouse stock update, daily 6pm"

Quicky → Rahul (6pm): "Hey Rahul, quick update on warehouse stock?"

Rahul → Quicky: "Received 200 units today, 50 pending from Pune"

Quicky → Manager (7pm): "📋 Daily Summary:
• Rahul (warehouse): Received 200, 50 pending from Pune ✅
• Priya (invoicing): No response ⚠️
• Amit (delivery): All 3 trucks dispatched ✅"

Features

  • 👥Whitelist mode — only registered users can interact
  • 📝Nudge templates — follow-up, status check, reminder, escalation
  • ⏰Scheduled nudges — daily/weekly at set times
  • 📊Response collection — summarizes replies for the boss
  • 🚨Escalation — "No reply in 24h → escalate to manager"
  • 🧵Thread tracking — each task has its own nudge thread
  • 💬WhatsApp + Telegram — your choice of channel

  • 📦Operations managers tracking deliveries
